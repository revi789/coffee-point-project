# Coffee Point — простой учебный проект

Backend сделан в одном файле `backend/main.py`, чтобы было проще изучать FastAPI.

## Запуск на Windows (PowerShell)

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

Открой сайт: http://127.0.0.1:8000
Документация API: http://127.0.0.1:8000/docs

## Что умеет backend
- отдаёт меню кофе и других товаров;
- хранит корзину посетителя в простой сессии;
- создаёт заказ;
- поддерживает демонстрационную оплату без списания денег;
- раздаёт файлы frontend.

## Важно
Это учебная версия: корзины и заказы хранятся в памяти и сбрасываются при перезапуске сервера. Для настоящего магазина нужно добавить базу данных и реальный платёжный сервис.
